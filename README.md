# 🚀 Transformative Technology Forecasting Platform

**Author: Pranay M.**

AI that identifies potential technologies that could fundamentally reshape civilization.

## 🌟 Features

| Module | Description |
|--------|-------------|
| **Emerging Tech Scanner** | Scan emerging technologies |
| **Transformative Potential Assessor** | Assess transformative potential |
| **Timeline Estimator** | Estimate development timelines |
| **Disruption Analyzer** | Analyze disruption patterns |
| **Convergence Detector** | Detect technology convergences |
| **Second-Order Effect Modeler** | Model second-order effects |
| **Societal Impact Forecaster** | Forecast societal impacts |
| **Governance Implication Analyzer** | Analyze governance implications |
| **Wild Card Identifier** | Identify wild card technologies |
| **Forecasting Dashboard** | View technology forecasting dashboard |

## 🚀 Quick Start

```bash
ollama pull llama3.2 && ollama serve
pip install -r requirements.txt
python main.py
```
